# 🏦 Banking System - Spring Boot Edition

Un sistem bancar modern dezvoltat cu Spring Boot, care evoluează dintr-o aplicație consolă Java într-o soluție enterprise completă.

## ✨ Caracteristici

### ✅ Implementate
- [x] Arhitectură Spring Boot cu layere separate
- [x] Persistență MySQL cu Spring Data JPA
- [x] Autentificare și autorizare
- [x] Interfață consolă interactivă
- [x] Management conturi bancare
- [x] Operațiuni: depunere, retragere, transfer
- [x] Istoric tranzacții

### 🔜 În dezvoltare
- [ ] REST API pentru integrare externă
- [ ] Interfață web cu Thymeleaf
- [ ] Rapoarte și statistici avansate
- [ ] Notificări email/SMS
- [ ] Docker containerizare
